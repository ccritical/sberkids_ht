# SberKids HT

Хакатонный Android-прототип на тему «Приколы»: детский интерфейс, в котором обычные дела превращаются в игровые задания. За выполнение можно получать награды, а копилки помогают следить за прогрессом к цели. Вместо серьезного банковского приложения здесь акцент на легких сценариях, иллюстрациях и небольших анимационных сюрпризах.

## Что внутри

- Четыре экрана прототипа: главный, копилки, дела и контент.
- Интерактивная навигация и анимированные переходы между вкладками.
- По нажатию «Снять 7 989,32 ₽» в «Копилках» проигрывается анимация попкорна, а карточка достигнутой цели плавно исчезает.
- Иллюстрация копилки реагирует на встряхивание устройства.
- При подключении питания поверх интерфейса появляются молнии и короткая вибрация.
- Демонстрационные балансы, история, задания и копилки для показа концепции.

**Важно:** интерфейс СберKids здесь используется как визуальный макет и оболочка для хакатонной идеи, а не как отдельная реализованная функция. Это демонстрационный прототип: данные экранов статичны, подключений к банковским сервисам и настоящих платежных операций нет.

## Технологии

- Kotlin и Jetpack Compose
- AndroidX и Material 3
- Lottie Compose для анимаций
- Gradle с Kotlin DSL
- JDK 21; Android SDK 35/36

## Сборка

Для сборки нужны JDK 21 и Android SDK с платформой Android 36.

```sh
./gradlew assembleDebug
```

APK для отладки появится в `app/build/outputs/apk/debug/app-debug.apk`.
Отладочная версия называется «SberKids Copy» и использует пакет
`com.sberkids.ht.copy`, чтобы сборки соседних проектов не заменяли её на устройстве.

В Nix-разработческой оболочке окружение и SDK настраиваются автоматически:

```sh
nix develop -c apk-build
```

Также доступны команды `apk-build-release`, `apk-install-adb` и `apk-install-waydroid` внутри `nix develop`.

## Структура

- `app/src/main/java/com/sberkids/ht/ui/screens/` — экраны прототипа.
- `app/src/main/java/com/sberkids/ht/ui/components/` — общие элементы интерфейса и анимации.
- `app/src/main/res/` — иллюстрации, шрифты и анимационные ресурсы.
- `design/` — исходные материалы и заметки по макету и движению иллюстраций.

## Контекст

Проект создан для хакатона. Название и пакет приложения (`com.sberkids.ht`) относятся к прототипу и сами по себе не означают интеграцию с продуктами или сервисами Сбера.
